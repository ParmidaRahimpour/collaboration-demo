# Collaboration Demo Project

This project is used to practice Git and GitHub collaboration workflows and team development.

## How to contribute
- Open an issue
- Create a branch
- Submit a pull request

## New Feature
This project can be extended with new collaboration features, such as issue tracking, pull requests, and code review.
## Contribution Steps

1. Open an issue describing the task.
2. Create a branch for the issue.
3. Make the required changes.
4. Submit a pull request for review.
